# Focus

אפליקציית Android ב-Java עם שלושה מסכים: פתיחה, כניסה והרשמה.

## המסכים

- **פתיחה:** סמל ממורכז שמופיע בהדרגה וגדל. לאחר 3 שניות עוברים למסך הכניסה. ההמתנה מתבצעת ב-Thread נפרד.
- **כניסה:** שם משתמש, סיסמה מוסתרת, כפתור כניסה וקישור להרשמה. נבדקים שדות ריקים והפרטים שנבחרו בהרשמה.
- **הרשמה:** שם משתמש, סיסמה ואימות סיסמה. נדרשים לפחות 6 תווים בסיסמה, ושתי הסיסמאות צריכות להיות זהות. הודעת שגיאה מוצגת ליד השדה המתאים.

אחרי ההרשמה חוזרים למסך הכניסה ושם המשתמש כבר מופיע. הפרטים עוברים ב-Intent extras בלבד, ללא קובץ או מסד נתונים. אחרי סגירה מלאה והפעלה חדשה יש להירשם שוב. כניסה מוצלחת מציגה הודעה.

## הרצה ב-Android Studio

1. מחלצים את הארכיון ופותחים את התיקייה `Focus` דרך `Open`.
2. בוחרים את התיקייה שבה נמצאים `settings.gradle` ו-`gradlew.bat`, ולא את התיקייה `app`.
3. ממתינים לסנכרון Gradle ומתקינים את רכיבי ה-SDK אם הם חסרים.
4. בוחרים אמולטור או מכשיר עם Android 6.0 ומעלה ולוחצים `Run`.

הגדרות הבנייה: JDK 17, Gradle 8.9, Android Gradle Plugin 8.7.3, compile SDK 35, Build Tools 35.0.0 ו-target SDK 34.

## פרסום ב-GitHub

הפרויקט כבר כולל היסטוריית Git. ב-Android Studio בוחרים `Git → GitHub → Share Project on GitHub`, מתחברים לחשבון האישי ומפרסמים את המאגר כ-Public. לאחר הפרסום בודקים שהקישור נפתח גם בחלון גלישה פרטית.
